## 🔥 ЧТО ДЕЛАТЬ СЕЙЧАС (2 шага):

### Шаг 1: Открыть порт 443 (2 минуты)

**На странице VK Cloud Firewall где ты сейчас:**

1. Кликни на **"default"** (синяя ссылка в таблице групп)
2. Нажми **"Добавить правило"**
3. Заполни форму:
   ```
   Направление: Входящий (Ingress)
   Протокол: TCP
   Порт: 443
   Удалённый IP: 0.0.0.0/0
   Описание: VPN Relay
   ```
4. Нажми **"Сохранить"**

### Шаг 2: Подключиться с телефона (1 минута)

**Скопируй эту строку целиком:**
```
vless://***REMOVED***@***REMOVED***:443?encryption=none&flow=xtls-rprx-vision&security=reality&sni=max.ru&fp=chrome&pbk=***REMOVED***&sid=10e9a626481fadde&type=tcp&headerType=none#Moscow-Relay
```

**Вставь в приложение:**
- **Android**: V2RayNG → "+" → "Импорт из буфера"
- **iOS**: V2RayTun → "+" → "Импорт из буфера"
- **Windows**: V2RayN → "Серверы" → "Импорт из буфера"

**Подключись** и проверь:
- Открой https://2ip.ru → должен показать Нидерланды
- Открой https://ifconfig.me → должен показать ***REMOVED***

## 🛠️ Если что-то не работает:

### Проблема: "Не подключается"
**Решение:**
1. Проверь что порт 443 открыт (команда выше)
2. Проверь что сервисы работают:
   ```bash
   # Москва
   ssh ubuntu@***REMOVED*** -i mybuntu-dVMXHugm.pem
   sudo systemctl status xray
   
   # Нидерланды
   ssh root@***REMOVED***
   systemctl status x-ui
   ```

### Проблема: "Медленно работает"
**Решение:**
1. Проверь пинг: `ping ***REMOVED***` (должно быть <100ms)
2. Проверь загрузку серверов: `htop`
3. Попробуй подключиться напрямую к Нидерландам (для теста)

### Проблема: "Обнаруживается DPI"
**Решение:**
1. Убедись что SNI = max.ru (не google.com)
2. Проверь что fingerprint = chrome
3. Проверь что flow = xtls-rprx-vision
